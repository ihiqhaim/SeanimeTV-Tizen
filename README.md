# 🎌 SeanimeTV-Tizen

A lightweight **Seanime client for Samsung Tizen 4.0 Smart TVs**, tested on the **Samsung NU7100 series**.

Watch your favorite anime online via torrent streaming or enjoy your personal library from the comfort of your couch. Featuring **full remote-control navigation** and **hardware-accelerated video playback**, SeanimeTV brings your anime experience to the big screen.

> 🤖 **Note:** This project was created with the assistance of AI.

---

## 📺 Installation

Follow these steps to install SeanimeTV on your Samsung Smart TV:

1. **Build the application** using Visual Studio Code and the Tizen extension.
2. **Download and open Apps2Samsung**, select the custom `.wgt` option, and install the generated widget package.

---

## 🛠️ How to Build

### Prerequisites

- [Visual Studio Code](https://code.visualstudio.com/)
- The **Tizen extension** for Visual Studio Code
- The SeanimeTV-Tizen source code

### Build Instructions

1. **Download the source code** of this project.
2. **Install Visual Studio Code** and add the Tizen extension.
3. **Open the project folder** in Visual Studio Code.
4. In the left sidebar, click the **Tizen extension** icon.
5. Click **Build** to compile the application.
6. Once the build finishes, find the generated `.wgt` package inside the project's `Debug` folder.

Your application is now ready to be installed on your Samsung Tizen TV!
